# Assembly sprint: original singer plus TWO converter-produced lyric words

This is an explicit attempt to move beyond isolated full-song timestamp
compilers and remote stage-only worlds. Retain the 8,090-cell singer's
rounded physical bubble, g2156 compact WE, pre-existing W-to-lip
and independent Suno V glider, cheek and actual lip contours.

Build a second original-Suno g2204 MADE as 32 genuine 3x4 LWSS pixels,
entering from above through 32 original one-shot 19-cell 90-degree
converters, emerging westbound into a SECOND row 144 native cells
below WE inside the same rounded bubble. Use original collision-eaters.
The second converter assembly is not a renderer-selected copy of a word.
We solve converter x displacement by backing out a corresponding
downward LWSS source y position without changing any intended readout.

The Actions workflow tests several literal g0 spatial offsets, runs an
independent C++ B3/S23 WHOLE-WORLD collision test, checks the second word
at its original g2204 and hardware recovery g3400, and only if a physical
candidate succeeds exports 481 native 24fps frames through g3840.
Failure evidence is preserved in per-candidate logs.

Important: a true second displayed word does not itself imply a second
causal control input to the singer's mouth. The existing W/V lip evidence
remains for the first word; extension to the 403-word real song/one-bubble
performance, repeated mouth control and the final zero-population ending
is NOT demonstrated here.

## Negative result and expanded physical search

The first one-row x-offset-only study failed, rather than validating
the assembly: at offsets -18, 0 and +18 the combined scene interfered
already at generation 1; other offsets collided at g586, g658 and g730.
No optical correction or physically false output was substituted.
The search was expanded to actual y placements 120..216 in 12-cell
steps (relative to the real original WE layout) and multiple independent
source/converter x offsets. Each candidate still derives from the
original Suno g2204 readout and original converter formula.
